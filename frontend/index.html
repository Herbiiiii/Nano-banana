API ключ генерации
Важно: API ключи сохраняются на сервере в зашифрованном виде. Это нужно для очереди автоповторов и возобновления после перезапуска сервера.
Replicate: ключ с префиксом r8_ — replicate.com/account/api-tokens.
Moonez (Nano Banana): ключ с префиксом bh_ (старые nb_ ещё принимаются) — moonez.ai (docs: docs.moonez.ai).
OpenRouter (GPT): ключ с префиксом sk-or — openrouter.ai/keys.
Ключи хранятся на сервере в зашифрованном виде. Модель выбирает провайдер автоматически. Для Moonez нужен IP whitelist в панели.
